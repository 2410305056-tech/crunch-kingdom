# ÉLAN ATELIER | Haute Coiffure, Bespoke Balayage & Sensory Scalp Sanctuary

> A luxury salon and holistic botanical hair spa web application built with **React 19**, **Vite**, **Tailwind CSS**, and **Lucide Icons**.  
> Designed under a 30-year veteran UI/UX ethos: quiet luxury, editorial typography, tactile micro-interactions, and flawless booking conversion.

---

## ✦ Key Interactive Modules & Features

### 1. **Interactive Bespoke Treatment Menu & Dynamic Multi-Currency**
* Filter across **Haute Cuts**, **French Balayage**, **Botanical Scalp Spa**, **Raw Silk Repair**, and **VIP Bridal Suites**.
* Real-time currency switcher (**GBP £**, **USD $**, **EUR €**) with dynamic price re-calculation.
* Interactive multi-ritual selector: add or remove services with running duration and investment totals.

### 2. **Interactive 4-Step Private Appointment Concierge (Drawer / Modal)**
* **Step 1: Curate Rituals** — Dynamic addition and removal of bespoke salon treatments.
* **Step 2: Select Master Stylist** — Choose between Founder Camille Laurent, Principal Colorist Julian Vance, Trichology Master Mei Lin, or Senior Texture Artisan Antoine Moreau.
* **Step 3: Date & Slot Picker** — Interactive calendar date selector with morning, afternoon, and evening suite slots.
* **Step 4: Guest Concierge & Digital Confirmation Pass** — Enter guest preferences (complimentary Ruinart Champagne, Uji Matcha, or quiet session requests) and receive an instant booking reference code (`ELN-2026-9812`).

### 3. **Editorial Before & After Transformation Studio**
* Side-by-side comparative case studies showcasing brassy-to-cashmere balayage, Parisian French bobs, and scalp follicle revitalization.
* Complete formulation details and stylist attribution.

### 4. **Botanical Hair Care Apothecary**
* Curated retail boutique featuring bio-fermented caviar oils, white truffle follicle tonics, raw silk biomimetic masques, and damask rose scalp mists with instant bag counter.

### 5. **International Press Acclaim & Concierge Details**
* Critical praise from *British Vogue*, *Harper's Bazaar*, and *Elle UK*.
* Complete atelier addresses in Mount Street Mayfair and Prince Street SoHo, operating hours, and private newsletter list.

## ✦ Quick Start & Local Development

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Compile production bundle
npm run build
```

## ✦ Deployment on Vercel

This repository is configured for 1-click deployment on Vercel:
1. Import repository into [Vercel](https://vercel.com/).
2. Framework Preset: **Vite**
3. Build Command: `npm run build`
4. Output Directory: `dist`
5. Deploy.
