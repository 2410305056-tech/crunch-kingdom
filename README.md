# Crunch Kingdom — Artisanal Reserve Acoustic Snacks (76.4 dBA)

> A high-craft, uncluttered full-stack web application built with React and Node.js for Crunch Kingdom, adhering strictly to the **Obsidian Saffron** design system.

---

## ✦ System Architecture & Improvements

### 1. Decluttered & Focused Hero Stage
* **Clean Visual Hierarchy**: Eliminates competing noise. Focuses user attention on the core hook (*"The 76.4 dBA Crunch"*), active flavor tabs, and immediate quick-commerce dispatch.
* **Dynamic Pack & Palette Transitions**: Switching flavor tabs (*01. Tikka Tang, 02. Nimbu Pudina, 03. Rock Salt, 04. Cheesy Makhani*) dynamically swaps the hero packaging artwork, batch codes, and ambient saffron/emerald/crimson glow.
* **Authentic Web Audio Synthesis**: Clicking *"Hear the Snap (76.4 dBA)"* generates a real procedural 2.4 kHz acoustic fracture sound directly via the native browser Web Audio API.

### 2. Streamlined Interactive Modules
* **The Science of The Crunch (3-Pillar Bento Grid)**: Acoustic metrology comparison, 100% clean label purity (0% palm oil, -35% oil centrifugal vortex spin), and 10-minute quick-commerce dark pods (Zepto, Blinkit, Instamart).
* **Quad-Pack Crate Builder (₹180)**: 1-tap instant curation presets (*The Balanced Quad, Fiery Lovers, Gentle Reserve*) with live 4-slot visualizer and instant one-click lock into cart.
* **The Signature Reserve Line Roster**: 4 individual reserve packs (₹50 / 65g) with curated Chai pairings (*Cutting Masala Chai, Iced Lemon Sulaimani, Adrak Ginger Chai, Kulhad Elaichi Chai*).
* **Slide-Out Dispatch Bag**: Replaces bulky mobile overlays with a sleek, non-intrusive drawer featuring free express delivery progress and automated 10-minute dispatch routing.

### 3. Full-Stack Node.js / Express Backend
* `GET /api/flavors` — Reserve catalog & acoustic specs.
* `GET /api/crate/presets` — Curated Quad Crate bundles.
* `GET /api/dispatch/status` — Live quick-commerce dark pod status (Mumbai, Bengaluru, Delhi NCR).
* `POST /api/orders` — Dispatches orders with verified batch codes and 10-minute delivery routing.
